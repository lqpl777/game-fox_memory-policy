Удаление данных — Memory Dan

Приложение Memory Dan (com.gamememory.memory), независимый разработчик. Контакт: Fox_Memory@qptex.kz.

Как запросить удаление

  1. Напишите письмо на Fox_Memory@qptex.kz с темой «Удаление данных — Memory Dan».
  2. Укажите ник, который виден в топах (например, «Шёлковый Мёд #3660»). Если ник менялся — перечислите все варианты, которые помните.
  3. По желанию: примерную дату последней игры и модель телефона — так найдём записи быстрее.
  4. Ответим с подтверждением, когда данные удалены. Срок — до 30 дней, обычно в течение одного дня.

Что удаляется

  • ник и анонимный идентификатор игрока;
  • результаты партий: режим, поле, время, ходы, очки, точность, победа/победитель, ключ соревнования, служебные данные партии (колода, seed, последовательность ходов, число смен имени);
  • после удаления результаты исчезают из мирового рейтинга, топа дня/недели и зала славы.

Что не требует запроса

  • Данные на телефоне (прогресс, монеты, XP, рекорды, настройки) удаляются вместе с приложением — просто удалите его.
  • Отчёты об ошибках и события игры не привязаны к нику и хранятся в сыром виде 90 дней, затем удаляются автоматически.
  • Аккаунтов с логином нет: регистрация не нужна, сервер создаёт анонимную сессию.
  • Если мировые топы были выключены, на сервере ваших данных нет — достаточно удалить приложение.

Data deletion — Memory Dan

App Memory Dan (com.gamememory.memory), independent developer. Contact: Fox_Memory@qptex.kz.

How to request deletion

  1. Email Fox_Memory@qptex.kz with the subject “Delete my data — Memory Dan”.
  2. Include the nickname shown in the leaderboards (e.g. “Windy Dolphin #9520”). If you changed it, list every version you remember.
  3. Optional: approximate date of your last game and phone model — it helps us find the rows faster.
  4. We reply with confirmation once the data is deleted. It takes up to 30 days, usually within one day.

What gets deleted

  • nickname and anonymous player id;
  • game results: mode, board, time, moves, score, accuracy, win/winner, contest key, service data of the game (deck, seed, sequence of moves, number of name changes);
  • after deletion the results disappear from the world rating, daily/weekly top and hall of fame.

What needs no request

  • On-device data (progress, coins, XP, records, settings) is removed with the app — just uninstall it.
  • Crash reports and game events are not linked to a nickname and are kept raw for 90 days, then deleted automatically.
  • There are no login accounts: no sign-up is needed, the server creates an anonymous session.
  • If world leaderboards were turned off, no data is stored on our server — uninstalling the app is enough.
