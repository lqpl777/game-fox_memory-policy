Русский

1. Кто мы

Независимый разработчик игры Memo Dan. Юрлица нет; контакт для вопросов о данных — Fox_Memory@qptex.kz.

2. Что хранится только на телефоне

Прогресс, монеты, XP, рубашки, рекорды, история игр, настройки (язык, звук, тема). Не покидает устройство, удаляется вместе с приложением.

3. Что уходит на наш сервер (Supabase, EU)

ДанныеЗачемСколько хранится
Ник + результаты игр (время, ходы, очки)мировые топы и соревнованияпока не попросите удалить
Отчёты об ошибках (версия, режим, уровень, текст ошибки, модель телефона, версия ОС)чинить падениясырые — 90 дней
События игры (режим, поле, уровень, язык игры)понимать, во что играютсырые — 90 дней, дальше только общие цифры
Анонимный id установкисвязать строки одного телефонапока не попросите удалить

IP-адрес автоматически видит хостинг (как у любого сайта), отдельно мы его не собираем и не храним.

4. Чего мы НЕ собираем вообще

Контакты, геолокация, микрофон/камера, SMS, список приложений, рекламные идентификаторы, данные банковских карт, точные данные о детях. Трекинга между приложениями нет (Google Signals выключен, рекламных SDK нет).

5. Кому видны данные

Supabase (хостинг в ЕС): хранит и обрабатывает таблицы по нашему поручению, соединение шифруется (TLS). Режим «Рядом»: два телефона обмениваются только ходами напрямую по Bluetooth. Никому не продаём, рекламным сетям не передаём (рекламы в игре нет).

6. Разрешения телефона

Устройства рядом (Bluetooth) — только для режима «Рядом», в момент входа, с объяснением. Геолокация не используется (neverForLocation). Интернет — топы, отчёты, статистика, проверка обновлений. Без сети игра работает полностью.

7. Согласия (настройки → Конфиденциальность)

Отчёты об ошибках: включены по умолчанию (персонального в них нет), выключаются тумблером. Статистика игры: выключена по умолчанию, включается только вами. Мировые топы: включены по умолчанию — без них нет рейтинга; выключаются тумблером, тогда ник и результаты остаются на телефоне.

8. Дети

Игра подходит всей семье (3+), рекламы нет. Данные детей собираются в том же минимуме: без рекламных идентификаторов и трекинга. Родитель может выключить отправку полностью и запросить удаление письмом.

9. Удаление

С телефона — сносом приложения. С сервера — письмом на контактный email (удаляем ник, результаты, id установки; срок — до 30 дней, обычно за день; анонимные отчёты без ника живут 90 дней и стираются сами). Аккаунтов нет, поэтому кнопки «удалить аккаунт» не требуется.

10. Безопасность

TLS при передаче; на сервере приложение может только добавлять строки, читать чужие и менять — нет.

11. Изменения

При изменении практики (например, реклама) выпустим новую версию документа, поднимем дату и покажем заметку в игре.
