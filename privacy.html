Действует с версии 0.112. Контакт: Fox_Memory@qptex.kz. Полный текст онлайн: lqpl777.github.io/game-fox_memory-policy/privacy.html

1. Кто мы

Независимый разработчик игры Memo Dan. Юрлица нет; контакт для вопросов о данных — Fox_Memory@qptex.kz.

2. Что хранится только на телефоне

Прогресс, монеты, XP, рубашки, рекорды, история игр, настройки (язык, звук, тема). Не покидает устройство, удаляется вместе с приложением.

3. Что уходит на наш сервер (Supabase, EU)

ДанныеЗачемСколько хранится
Ник + результаты партий (режим, поле, время, ходы, очки, точность, победа/победитель, ключ соревнования)мировые топы и соревнованияпока не попросите удалить
Отчёты об ошибках (версия, режим, уровень, текст ошибки, модель телефона, версия ОС, действия перед ошибкой)чинить падениясырые — 90 дней
События игры (действие, режим, поле, уровень, результат, длительность, язык, версия)понимать, во что играютсырые — 90 дней
Анонимный идентификатор игрока (без входа и email)связать строки одного устройства между собойпока не попросите удалить

IP-адрес автоматически видит хостинг (как у любого сайта), отдельно мы его не собираем и не храним.

4. Чего мы НЕ собираем вообще

Контакты, геолокация, микрофон/камера, SMS, список приложений, рекламные идентификаторы, данные банковских карт, точные данные о детях. Трекинга между приложениями нет (Google Signals выключен, рекламных SDK нет).

5. Кому видны данные

  • Supabase (хостинг в ЕС): хранит и обрабатывает таблицы по нашему поручению, соединение шифруется (TLS).
  • Режим «Рядом»: два телефона обмениваются ником, списком колод и ходами напрямую по Bluetooth, через серверы ничего не идёт.
  • Никому не продаём, рекламным сетям не передаём (рекламы в игре нет).

6. Разрешения телефона

  • Устройства рядом (Bluetooth) — только для режима «Рядом», в момент входа, с объяснением. Геолокация не используется (neverForLocation).
  • Интернет — топы, отчёты, статистика, проверка обновлений. Без сети игра работает полностью.

7. Согласия (настройки → Конфиденциальность)

  • Отчёты об ошибках: включены по умолчанию (персонального в них нет), выключаются тумблером.
  • Статистика игры: выключена по умолчанию, включается только вами.
  • Мировые топы: включены по умолчанию — иначе рейтинга нет; выключаются тумблером, тогда ник и результаты остаются на телефоне.

8. Дети

Игра подходит всей семье (3+), рекламы нет. Данные детей собираются в том же минимуме, что у всех: без рекламных идентификаторов и трекинга. Родитель может выключить отправку полностью и запросить удаление письмом.

9. Удаление

  • С телефона — сносом приложения.
  • С сервера — письмом на контактный email (удаляем ник, результаты, анонимный id игрока; срок — до 30 дней, обычно за день; анонимные отчёты без ника живут 90 дней и стираются сами). Аккаунтов с логином нет: вход не нужен, сервер создаёт анонимную сессию. Кнопки «удалить аккаунт» не требуется — данные удаляются по письму.

10. Безопасность

TLS при передаче; на сервере — строгие права (приложение добавляет свои строки и читает опубликованные результаты для топов; менять или удалять чужие строки не может).

11. Изменения

При изменении практики (например, реклама) выпустим новую версию документа, поднимем дату и покажем заметку в игре.

Independent developer of the Memo Dan game. No legal entity; contact for data questions — Fox_Memory@qptex.kz.

Progress, coins, XP, card backs, records, game history, settings (language, sound, theme). Never leaves the device; removed with uninstall.

4. What we NEVER collect

Contacts, location, microphone/camera, SMS, installed apps, advertising IDs, payment data, children's sensitive data. No cross-app tracking (no Google Signals, no ad SDKs).

5. Who sees the data

  • Supabase (EU hosting): stores tables on our behalf, TLS-encrypted.
  • “Nearby” mode: two phones exchange the nickname, the list of decks and moves directly over Bluetooth; nothing goes through servers.
  • Nothing sold, nothing given to ad networks (no ads in the game).

6. Phone permissions

  • Nearby devices (Bluetooth) — only for “Nearby” mode, asked at entry with explanation. No location (neverForLocation).
  • Internet — tops, reports, stats, update checks. The game fully works offline.

7. Consent (Settings → Privacy)

  • Crash reports: on by default (nothing personal inside), toggle to turn off.
  • Game stats: off by default, opt-in only.
  • World leaderboards: on by default (otherwise no rating); toggle turns them off and keeps nickname and results on the phone.

8. Children

Family-suitable (3+), no ads. Children's data follows the same minimum: no ad IDs, no tracking. A parent can disable all upload and request deletion by email.

9. Deletion

  • From the phone — by uninstalling.
  • From the server — by email (nickname, results, anonymous player id; within 30 days, usually a day; anonymous nick-less reports live 90 days and expire automatically). There are no login accounts: no sign-in is needed, the server creates an anonymous session. No “delete account” button is required — data is deleted by email request.

10. Security

TLS in transit; strict server rules (the app adds its own rows and reads published results for the tops; it cannot change or delete anyone else's rows).

11. Changes

New practices (e.g., ads) get a new document version, date, and an in-game note.

TLS em trânsito; regras rígidas no servidor (o app adiciona as próprias linhas e lê os resultados publicados para os topos; não altera nem apaga as dos outros).

Novas práticas (por exemplo, anúncios) recebem nova versão do documento, data e aviso dentro do jogo.
